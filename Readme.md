# TrustGrid Africa

TrustGrid Africa is an open-source cybersecurity and digital trust platform for small and medium organisations across Africa. It is designed to help teams assess digital assets, understand security risks, manage remediation, and share vetted cybersecurity knowledge.

## Project vision

The platform supports organisations such as NGOs, schools, clinics, community groups, social enterprises, and small businesses that need practical security assessment guidance without the cost of enterprise consultancy services.

## Included demo experience

This repository contains a responsive static prototype that demonstrates the platform's core experience:

- landing page overview
- security dashboard with risk trends and findings
- asset register management view
- report generation example

## Quick start

Open `index.html` directly in a browser, or serve the folder locally:

```bash
cd "c:\wamp64\www\TrustGrid Africa"
python -m http.server 8000
```

Then open:

- http://localhost:8000/

## Technology direction

The project follows the strategic stack described in the master development prompt:

- PHP 8.2+ backend
- MySQL 8 data storage
- REST API architecture
- Bootstrap 5 + JavaScript front end
- Python for specialised security assessment engines

## Core platform modules represented in the prototype

- Organisation management
- Digital asset management
- Security assessment workflows
- Risk dashboard
- PDF-style security reports
- Remediation and monitoring
- Knowledge base and shared security infrastructure

## Notes

This repository is intentionally a front-end demonstration prototype to establish the product vision and user experience. It can be expanded into a full application using the architecture described in the project brief.
